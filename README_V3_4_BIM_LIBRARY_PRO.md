# RJP 3D Studio V3.4 — BIM Library Pro

## Biblioteca visual
- cartões maiores e mais legíveis;
- badge 3D e miniaturas específicas por família;
- melhor correspondência entre miniatura e objeto inserido.

## Geometria procedural reforçada
- sanita, bidé, urinol, banheira, lavatório, duche e lava-louça;
- cadeira, mesa/secretária, sofá, cama, armário, estante e banco;
- extintor, painel solar, equipamentos AVAC/elétricos, rack, poste/luminária, contentor, andaime e veículo simples;
- continuam paredes, vigas, pilares, portas, janelas, escadas, tubagens, condutas, coberturas, árvores e restantes elementos.

A geometria continua leve e parametrizada pelas dimensões BIM, evitando carregar modelos externos pesados para cada objeto.
