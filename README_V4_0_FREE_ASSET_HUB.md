# RJP 3D Studio V4.0 — Free Asset Hub

## Biblioteca interna
Mantém as famílias BIM procedurais existentes.

## Poly Haven CC0
Novo separador `Biblioteca Livre`:
- consulta o catálogo público de modelos Poly Haven;
- pesquisa online e mostra miniaturas reais;
- resolve automaticamente uma variante GLB/GLTF;
- importa o modelo para o projeto;
- o ThreeViewport carrega o GLTF externo em tempo real;
- mantém fonte, licença CC0 e autores nos `properties` do elemento;
- identificação `Powered by Poly Haven` visível na interface.

## Arquitetura
A app não copia automaticamente bases com licenças restritivas. O conector foi preparado para fontes de licença clara.
Próxima fonte recomendada: ambientCG para materiais PBR CC0.
