# RJP 3D Studio V1.6 — Integrated Project

Evolução significativa da V1.5 focada no fluxo completo CAD/BIM → projeto → medições → orçamento → planeamento → obra → autos.

## Novidades
- Centro do Projeto / dashboard com valor contratual, executado, execução física, elementos BIM, capítulos e ocorrências.
- Ribbon CAD com grupos Desenhar, Modificar, Anotar/Vista e estado SNAP/ORTHO/OSNAP.
- Planeamento editável com início, duração, predecessora, progresso e estado por atividade.
- Acompanhamento de Obra com diário, ocorrências, inspeções/entregas/reuniões e estado aberto/resolvido.
- Autos com navegação/resumo financeiro por número de auto.
- Fluxo visual integrado CAD/BIM → MQT → Orçamento → Planeamento → Obra → Autos.
- Mantida a biblioteca V1.5 com 257 componentes e 50 materiais, DXF→BIM, IFC, MQT e caderno técnico.

## Persistência
Projeto, artigos, autos e registos de obra são guardados localmente no browser.
