# RJP 3D Studio V2.9 — PAN & UX

## Navegação CAD
- ferramenta **PAN / Mão** dedicada;
- PAN com botão esquerdo quando a ferramenta está ativa;
- botão do meio do rato faz PAN permanentemente;
- botão direito mantém navegação/orbita no 3D;
- `H` ativa PAN;
- `Esc` volta a Selecionar e cancela cadeias de desenho;
- `F` executa Enquadrar Tudo;
- botão **Enquadrar** na ribbon e no cabeçalho do viewport;
- cursor muda em modo PAN.

## Melhorias genéricas
- ribbon CAD sticky;
- barra de estado mais clara com modo, OSNAP e vista;
- painel de Propriedades recolhível;
- toolbar do viewport reorganizada;
- layout responsivo melhor para ecrãs mais estreitos;
- micro-feedback visual nos botões;
- instruções de rato/atalhos diretamente no editor.

Mantém integralmente o CAD→BIM multi-piso, alinhamento por 2 pontos, DWG WASM, biblioteca, MQT, orçamento, planeamento, obra, autos e folhas.
