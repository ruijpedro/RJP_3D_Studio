# RJP 3D Studio V1.3.0 — CAD → BIM + Editor 3D

Evolução focada no fluxo de modelação:

- Editor 3D com modos Mover, Rodar e Escalar e snap de 5 cm / 5°.
- Propriedades numéricas de posição, dimensões e rotação.
- Biblioteca BIM ampliada (estrutura, alvenarias, LSF, madeira, coberturas, acabamentos, instalações, mobiliário, sanitários e exterior).
- Importação DXF ASCII no browser (LINE e LWPOLYLINE).
- Pré-visualização vetorial DXF.
- Conversão de segmentos DXF em paredes BIM parametrizadas com escala, altura e espessura editáveis.
- PDF e imagens continuam disponíveis como bases gráficas.
- DWG/DWF/DWFx são reconhecidos e preservados; geometria nativa requer conversão para DXF/IFC ou adaptador CAD desktop.
- IFC continua a ser o formato BIM de intercâmbio.

Nota: a conversão CAD → BIM é uma base assistida de modelação e deve ser revista pelo utilizador; linhas CAD não equivalem automaticamente a paredes construtivas.
