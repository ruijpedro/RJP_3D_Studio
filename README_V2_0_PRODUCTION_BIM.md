# RJP 3D Studio V2.0 — Production BIM

Evolução da V1.9 orientada à produção de projeto.

## Novidades
- Vistas ortográficas: Planta, Frente, Direita e 3D.
- Gestor de layers CAD dentro do workspace BIM, com visibilidade por layer.
- Mudança de piso reposiciona automaticamente o elemento pela cota do nível.
- Validador BIM: IDs duplicados, níveis, materiais, dimensões e vãos sem parede hospedeira.
- Contadores de fases Novo / Existente / Demolir.
- Exportação de pacote de projeto RJP-STUDIO 2.0 em JSON, incluindo modelo, MQT/orçamento, planeamento, autos, obra e metadados CAD.
- Mantém DWG/DXF → BIM assistido, sobreposição CAD, 257 elementos BIM, orçamento, planeamento, obra e autos.

## Direção V2
O modelo passa a ser a fonte comum de informação para peças desenhadas, medições, orçamento, planeamento e autos.
