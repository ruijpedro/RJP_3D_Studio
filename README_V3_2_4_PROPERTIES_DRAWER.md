# RJP 3D Studio V3.2.4 — Properties Drawer

## Alteração de interface
- o painel **Propriedades fica fechado por defeito**;
- quando fechado, não ocupa largura do viewport;
- permanece apenas uma pequena aba/seta na margem direita;
- clicar na seta abre o painel em overlay;
- clicar novamente fecha-o;
- o botão `⚙ Propriedades` da barra superior também controla o painel;
- o viewport mantém a largura disponível enquanto o painel está fechado;
- comportamento adaptado para ecrãs mais pequenos.

Objetivo: deixar o CAD/BIM/3D limpo e maximizar a área de desenho.
