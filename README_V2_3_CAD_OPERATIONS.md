# RJP 3D Studio V2.3 — CAD Operations

A V2.3 aprofunda o editor CAD/BIM da V2.2.

## Implementado
- **Copy** do elemento selecionado;
- **Mirror** por eixo vertical X definido pelo utilizador;
- **Offset** real de paredes por distância;
- **Trim/Extend** da parede selecionada até à parede mais próxima não paralela;
- análise **Join L/T/X** para encontros automáticos;
- **Cotas associativas 2D** por dois pontos com OSNAP e valor em metros;
- motor geométrico expandido com interseções infinitas, offset e reflexão;
- mantém desenho clique-a-clique, deteção de compartimentos fechados, DWG/DXF→BIM, layers, níveis/fases, MQT, orçamento, planeamento, obra, autos e folhas.

## Próxima evolução
Recorte CSG físico de portas/janelas, representação gráfica das cotas no viewport, grips CAD e folhas PDF A1/A3 com viewports.
