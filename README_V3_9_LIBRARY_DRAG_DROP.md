# RJP 3D Studio V3.9 — Library Drag & Drop

## Biblioteca ↔ viewport
- famílias da Biblioteca e do dock são arrastáveis;
- largar diretamente no viewport calcula a posição no plano do piso ativo;
- aparece uma pré-visualização fantasma semitransparente;
- o fantasma segue o rato durante colocação;
- `R` roda a família 90° antes da colocação;
- `Esc` cancela;
- duplo clique e `Inserir por clique` continuam disponíveis;
- após colocar, o elemento fica selecionado para Mover/Rodar/Escalar;
- `Substituir selecionado` continua a permitir trocar famílias sem perder posição/rotação.

Objetivo: tornar a Biblioteca parte do próprio processo de modelação, reduzindo cliques e mudanças de página.
