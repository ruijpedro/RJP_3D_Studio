# RJP 3D Studio V3.0 — CAD / BIM / 3D Workspace

A interface do editor foi reorganizada para uma lógica mais próxima de software CAD/BIM profissional.

## Novo workspace
- modos principais CAD, BIM e 3D;
- CAD abre diretamente a vista em planta;
- 3D abre diretamente a perspetiva;
- BIM mantém modelação e propriedades;
- navegador do projeto à esquerda;
- propriedades à direita;
- viewport central maior;
- painéis podem ser mostrados/ocultados;
- vistas Planta, Frente, Direita e 3D acessíveis numa barra rápida.

## Navegador do projeto
- vistas;
- níveis/pisos com cota;
- acesso a folhas, MQT e orçamento;
- filtro visual preparado para crescimento futuro.

## Viewport
- PAN, Enquadrar, mover, rodar e escalar;
- estilos visuais Shaded, Edges e XRay;
- estado do workspace, nível, OSNAP, vista e número de elementos;
- empty-state com acesso imediato à importação CAD e Biblioteca.

## Ergonomia
- layout desktop de 3 painéis;
- aparência técnica mais compacta;
- propriedades com inputs de maior contraste;
- viewport ocupa a maior área possível;
- adaptação para ecrãs menores;
- mantém os atalhos H, F e Esc da V2.9.

Toda a cadeia CAD→BIM, DWG WASM, múltiplos pisos, alinhamento, biblioteca, MQT, orçamento, planeamento, obra, autos e folhas foi preservada.
